CommController

object CommController

Controlador de comunicacions encarregat de gestionar les peticions HTTP amb el servidor. Aquest objecte centralitza les crides a l'API de Coffriend, gestionant l'autenticació mitjançant tokens de sessió i la serialització de dades amb Gson.
